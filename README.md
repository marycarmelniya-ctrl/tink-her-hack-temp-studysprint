### Project Description
StudySprint is a clean and minimal smart study planner designed to help students manage tasks, track focus sessions, and visualize progress using an integrated timer and task system.

### The Problem Statement
Students struggle with maintaining focus, organizing study tasks, and tracking productivity during long study sessions. Many tools are either too complex or distracting.

### The Solution
StudySprint combines:
- Task management
- Focus timer
- Progress tracking
into a simple distraction‑free interface that encourages productive study habits.
